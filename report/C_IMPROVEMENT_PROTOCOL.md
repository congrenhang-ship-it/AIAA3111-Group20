# C 改进实验协议（第二轮）

负责人 C，2026-11-11。现有 results/c_validation/ 及其冻结配置保留为第一轮基线。此前已查看正式验证段的 57 笔欺诈结果；本轮属于后续开发，不能把它描述为从未查看过的独立验证。

## 先固定候选，再运行

- 原始字节、去重与正式三段划分仍完全复用 A。测试段不打分、不参与任何选择。
- 为减少围绕 57 笔验证欺诈挑配置，本轮在 A 的训练段内部建立一次 80/20 时间开发划分：按排序后 80% 位置的时间戳切分，同时间记录进入后段。内层前段拟合、后段选择。它不替代 A 的正式划分。
- 内层比较三个固定种子 42/43/44。按内层 1% 预算下平均 TP 最大选，每个方法并列按平均 AP，再按候选列表先后（较早候选优先）。不能按正式验证效果重新选候选。
- K-means 固定 k=3、n_init=10，隔离特征/缩放/评分改动；不重复搜索 k。六种拟合配置：原始标准化、去 Time、log1p(Amount)、去 Time+log 金额、原始 RobustScaler、去 Time+log 金额+RobustScaler。每种提供原始距离与簇内相对距离，共 12 个评分候选。
- 相对距离=(距离−所属簇训练距离中位数)/所属簇训练距离 IQR。统计量只在拟合段计算；零 IQR 使用明确的正下界，不删除异常交易或按标签筛正常样本。
- IF 八种配置：原始 100 棵/256 抽样；去 Time；log 金额；去 Time+log 金额；仅抽样改 1024；仅抽样改 4096；仅树数改 300；预先指定联合配置“去 Time+log 金额、300 棵、1024 抽样”。其他参数固定，所有 IF 使用 StandardScaler。没有额外的笛卡尔积搜索或按结果添加参数。
- 先在内层分别选距离候选与 IF 候选。两者等 K 名单组合的距离配额候选为 0/25/50/75/100%；按三种子平均内层 TP 选，并列优先纯方法，再优先更大距离配额。此名单策略只在主预算选一次。
- 内层选择锁定后，所有 20 个候选用完整 A 训练段、固定 seed=42 重拟合并统一报告正式验证结果，作为预先指定的消融对照。正式验证结果用于确认和解释，不回流选择；即便别的候选验证数值更高，也不替换内层选择。
- 验证显示的候选很多，最大值存在选择偏差；不把最佳单格当作无偏泛化成绩。保留初始基线、未改善的设置与取舍。主要预算仍为 1%，同时报告 0.1/0.5/2% 和 AP。
- 不剪裁/删掉高额或极端正常交易，不按欺诈标签筛训练数据，不增加客户身份/时序假设，不用 contamination 调 top-K。所有拟合、相对距离标定均不使用训练标签；内层选择明确使用内层标签。
